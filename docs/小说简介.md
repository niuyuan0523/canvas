# 《巷陌人家》小说简介

## 一句话梗概

上海老弄堂最后一批住户面临旧改搬迁，一个刚毕业的社区规划师与一位守了四十年修鞋摊的老匠人，在“拆与留”的拉锯中，共同为一条巷子寻找第三条路。

## 内容简介

二十四岁的林知遥从同济城市规划专业毕业，被分到街道旧改办，参与长春里片区的成套改造意愿征询。她带着教科书里的理想走进弄堂，第一次踏勘就被晒在绳上的花裤衩和煤球炉的烟熏得直咳嗽，也被修鞋摊的老周头塞了一双“走路不磨脚”的旧布鞋。

她画得出精确到厘米的动迁红线，却画不进二楼阿婆朝南的骨灰龛、裁缝铺搬不动的老缝纫机、三家共用算不清的水表账。第一次入户，她被居民轰出门，蹲在弄堂口掉眼泪，老周头递给她一碗绿豆汤：“你先把鞋换了，再进来。”

六十八岁的周德顺在弄堂口摆了四十年修鞋摊。他不反对旧改，只想给弄堂求一个“留得下人情”的搬法。在他的带领下，林知遥放弃了“一刀切”，用一部手机拍下七十二家房客的生态，画出“一楼公共厨房、二楼保留居住、弄堂口修鞋摊保留为社区便民点”的微更新方案，为这条巷子争取到了“一巷一策”试点。

拆与留之间，第三条路不是画出来的，是走出来的。

## 题材与主题

- 题材方向：城市更新与社区生活，基层规划师视角的“行业+时代”叙事。
- 主题落点：城市更新不是推倒重来，而是让老弄堂里的人情脉络在新空间里继续生长。最动人的时代经验，藏在修鞋摊的锥子、灶披间的煤球炉和一碗绿豆汤里。

## 体量与结构

- 全书约五十万字，七十五章，四幕结构，每章正文两千三百字左右（不含标点不少于两千零五十字）。
- 分卷：第一卷“笔直的线”（第1—15章），第二卷“第三条路”（第16—40章），第三卷“留与走”（第41—60章），第四卷“新巷陌”（第61—75章）。
