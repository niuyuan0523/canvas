# 《巷陌人家》写作规范与生成约定

## 文本格式铁律

- 所有对话引号一律使用中文弯引号“”，嵌套时用单弯引号‘’；严禁英文直引号。
- 正文一律不使用加粗样式；强调内容通过叙事与短句表达。
- 账目、本子记录、白板文字等均以普通文本呈现。

## 章节文件铁律

- 章节文件一律使用 .txt 格式，存放于 chapters/ 下对应的分卷目录：
  - chapters/第一卷 笔直的线/（第001—015章）
  - chapters/第二卷 第三条路/（第016—040章）
  - chapters/第三卷 留与走/（第041—060章）
  - chapters/第四卷 新巷陌/（第061—075章）
- 文件命名格式为「第XXX章 标题」，章号三位数补零，章号与标题之间用空格分隔，如「第001章 三百米红线」。
- 正文直接从内容开始，文件开头不写任何标题行。
- 生成或改写后运行 scripts/count.js 校验字数与格式（脚本递归扫描各分卷目录）。

## 字数铁律

- 每章正文两千三百字左右，不含标点符号的字数不少于两千零五十字。
- 生成每章后需用脚本校验：去除标点与空白后的汉字数达标方可通过。

## 叙事文风铁律

- 推进方式：以“人物互动”而非“事件说明”推进——动作、反应、对话、另一人反应、再透露信息；避免“发生一件事、解释这件事、总结这件事、下一件事”的说明腔。
- 展示而非告知：不直接写“他紧张、她在意、这消息很重要”，改用眼神、停顿、语气、沉默、手上小动作让读者自行得出结论；重要线索先只给一半，让人物的沉默、对视、改口替读者意识到分量，再逐步揭示。
- 话外之意：对白不只传递信息，允许试探、调侃、遮掩、反问、答非所问、说半句；人物口是心非（嘴上说不在乎、动作露出在意）；不同人物有各自的说话习惯。
- 动作服务人物：可插入短动作（放茶杯、抬头、顿一下、没接话、笑一声、皱眉），但必须服务于性格与情绪，不得机械堆砌。
- 动作节制：单独成行的“他顿了顿、没人答、过了半晌”一类停顿，能并入对白或叙述的就合并，不逐句单列；同一处情绪震动只保留最强的一个反应；说话提示词多用朴素的“说”，不每句都配动作加“说”；只有当动作承担信息或人物性格时才保留。整体把刻意动作压到叙述自然为止（参考基准：对初稿再删约两成到三成）。
- 段落与对白密度（可量化，用于自查）：全书以短段推进，一段只说一件事。“独立成段的对白”按段首是前引号计。既有基准为第一卷每章约一百一十段、独立成段的对白约六十八处，第二卷约一百二十四段、八十处，第三卷约七十一段、三十九处，第四卷约八十七段、三十七处（第四卷各章最低七十六段、三十处）；对白中位长度第一卷十字、第二卷十三字、第三卷二十一字、第四卷二十二字。新写或改写章节应落在这一量级：每章不少于七十段，独立成段的对白不少于三十处，凡有人说话的场面，把长陈词拆成一来一往的短回合，中间只插必要的短动作或另一人反应；不得把三四个人的话压进一个长段，也不得用叙述转述代替本可写成对白的现场话。
- 同一个人连着说两三段时，段与段之间插一个短动作或停顿（“陈志强停了一下。”一类）交代说话人未换，免得读者错认；换人说话的段落可省提示词，靠一问一答的次序自明。
- 语言克制：少堆砌成语与形容词，少用“震惊、愤怒、无比、顿时、意味深长”等模板词；优先具体动作与现场细节。
- 悬念自然：靠人物行为与信息缺口制造悬念，严禁“他不知道的是、真正的秘密才刚刚开始、没人知道、而此时、事情远没有那么简单”这类堆砌式悬念句。
- 节奏与底线：有画面、有对话、有人物、有信息、有悬念，但不拖沓；文风改写绝不可改动剧情事实、人物关系与身份、时间线、事件因果和关键线索，不得擅自增删重大剧情。

- 时间轴：二〇二五年三月（惊蛰后）开工，头一个拆亭子间；主体施工八个月（三月—十一月）；过渡房八个月；十一月改造完成、回迁核验（老周头十一月十四号星期四回迁）；十二月新巷陌落成、记忆墙搬入记忆展廊、长春里列全市微更新样板（区里下文可复制可推广）；十二月下旬现场会；二〇二六年三月老周头刻“巷陌人家”、林知遥定去留；二〇二六年四月社区活动室开放（大结局）。与三月开工构成一个整年。
- 开工与拆亭子间：赵主任不放炮、不剪彩，“开工就是开工”。亭子间头一个拆，三百二十七块砖起下（碎十九），旧砖按协议附件放新墙里层（王秀娟那条改过来、也用在亭子间上），码场地盖帆布等主体起来砌回。墙上日历停在一九八〇年三月，老周头连一小块墙皮一起起下、包好，回迁时挂进新屋正对门。工具墙那块门板搬进服务站临时点（13号烟纸店隔壁，离梧桐二十步），锥子往里挪半寸（右手还使不上劲）。
- 服务站临时点：施工八个月在13号隔壁，木牌仍是“巷陌便民服务站”、点上写巷陌不写老周头名字。轮值表照排（早七点到八点、一天两人、十四格）；施工期车少、看车淡，借工具、代收快递、修鞋不断。代收快递按门牌分格、28号登记从无错发；看车、代收都不写在牌子上、靠人。落成后临时点转正为正式点（仍居委会名义、法律主体不变、每月三百块补给点不补给个人），旧木牌“社区便民服务点”钉进记忆展廊。
- 过渡房：5号、33号位置四十一平方米做四间（各八点二使用面积），四户周德顺、沈金凤、李国祥、徐家姆妈，改造八个月住。沈金凤机台靠墙那间（18号改造、机台一时下不来也上不去）；李国祥门宽七十公分、坡道施工先走临时铁板便道；徐家姆妈开门朝梧桐、柜子修稳、夜灯扶手到位。共用水斗排队、走道灯改感应。过渡房是改造期住的、不是回迁分的，回迁看原住房具备回迁条件并核验。
- 施工期磨合（第063章）：围挡把弄堂分成两半。三桩投诉——方阿婆报纸落灰改湿切；郑师傅招牌落灰，渣土车避钟点、盖帆布、每天冲；材料靠小车推肩膀扛（八十八公分大车进不来），费小军外卖车改行运料、28号焊挡板。7号山墙燃气撞无花果树主根、断一半，赵主任“第四个办法”两千块他出（公共部位省出来），燃气管绕开主根多用六米管，园林救根（生根粉覆土浇三个月）；张根发在图边又画一棵树、加“二〇二五年根断一半救活了”。图上标了字就要认。
- 7号山墙无花果树：树不挖（张根发底线），7号山墙重砌、沿墙阻根板一米二深、墙外四十公分宽排水明沟、四千二百元列公共部位，图上标“23号张根发，一九八八年种”。施工中主根断一半、救活，树保留。
- 共享厨房（第066章）：改造后六十二户独用厨房（独用厨房零户到六十二户、燃气进户、一户一灶独用才装表）。12号灶披间三家（王秀娟、陈志强、租东厢小两口）自愿保留共用，做成共享厨房——图上写“厨房”不写“附属搭建”、旧砖放新墙里层、燃气进户装表通给水。那张“三家互相欠的，不在纸上”裱起来挂墙上，三家共用十六年的旧水表拆下、王秀娟交存入记忆展廊。郑阿根一九八八年砌灶披间、一九九八年做平改坡九天三百六十块、二〇二五年燃气进户，“改过两回两回都没有拆”。
- 施工名单（第067章）：赵主任交代，一九九八年平改坡有手写名单（第十四个名字泥工郑阿根、王秀娟复印盖查档章钉灶披间门框），这一回改造也造名单、谁做了工都写上、不看有没有票。泥工头一个姓陈、砌旧砖、做九天（呼应郑阿根九天）；杂工栏有费小军（运料三十七天）、28号（帮工、工具整理；项目经理要写大名，28号讲“我没大名”，林知遥讲“这栏写做工的人不写户口”）。两份名单并排入记忆展廊，隔二十七年。老周头讲铁皮盒是“过日子的名单”、一九九八是“修房子的名单”、两份都在记忆墙上。
- 台风夜（第068章）：八月台风，停工加固。夜里十一点风到，围挡掀一角、临时点彩钢瓦掀一半，老周头、28号、费小军三人顶风加固半个钟头、工具墙未淋（费小军仍穿那件外卖马甲）。李国祥坐轮椅喊了一夜（谁窗没关、谁沟堵了），郑师傅装门板烧姜汤，王秀娟拎塑料布盖东西，沈金凤接墙渗水守缝纫机，李甜甜风雨里拍。孙姓女人两处过渡房人转移高处、低处进水半尺人无碍。林知遥走一夜一户一户记。老周头讲这一夜跟郑阿根挑水四百二十六担一样“没有人叫、自己来”；郑师傅讲“水不用挑了，那个自己来还在”。房没塌人没伤，赵主任停工检修一天。
- 周航往来（第069章）：和解后常态往来，一个多月来一回（太仓到上海一个钟头高铁），硬壳箱一角白印仍在。九月他带那双深棕皮鞋（鞋跟外侧又磨），老周头钉跟、28号打下手（右手握锤慢、敲得下去、外侧多钉两枚），写票“长春里 六十四 周 男鞋一双 钉跟 一元”，与去年十一月那张并排、两张都折四折放里袋。“六十四”是亭子间门牌（投票日算第六十四户），亭子间拆了、砖砌回里层、人住过渡房回迁5号位置，票上仍写六十四。周航讲明白了父亲守的是名字、是人、是“没有人叫自己来”的夜晚，台风夜他在太仓打电话哭了；讲这一回不劝了、你留着守着、你老了动不了我再接、接到哪里你讲。老周头讲哪里都不去、票攒多了也上记忆墙。
- 记忆墙搬家（第070章）：居委会一楼随改造要动，记忆墙搬到新社区活动中心一楼长廊“记忆展廊”，逐格拆、逐格核来源、编号打包（七只箱子），规矩不变（来源不清的暂不进展廊）。第一格老周头自己拆、28号软布包、箱上写“第一格勿压”；28号自己拆自己那格并念票；孙姓女人来看她那格搬、讲“我没有户，我有一格”；姚凤仙念二十三行七分四十秒。靠下一格夹一张来源不清的黑白照片，暂不进展廊；次日问出是方阿婆与其兄长约一九五几年弄堂口梧桐下所摄、兄长赴北方未归、原藏樟木箱搭墙时掉出，来源核清、挂方阿婆格旁（“兄妹都在墙上”）。
- 回迁（第071章）：十一月改造完成，回迁以原住房具备回迁条件并核验为准，林知遥带核验表一户一户打勾，六十二户格子满。老周头回迁5号位置那一间：门朝东、看得见弄堂口梧桐与服务站、“我从尾搬到中段往人多的地方搬”；坡屋面层高最低两米二中间段两米四、轻质隔断贴斜边；厨房原天井位置二点四封闭、燃气一户一灶装表；卫生间从走道借一点六、家具从窗口吊入；日历挂新屋正对门。方案文本仍不写平方米数（葛科警告：写了要负责），老周头只问“开门看得见弄堂口吗”。各户诉求兑现：王阿婆一楼开门看弄堂一天三回；徐家姆妈开门朝梧桐、柜子夜灯扶手到位；李国祥水泥坡道自己摇出去（“我要自己出去”三秒）；许国良图上两户、扣子扣着、准话兑现、儿子下月回来住第二户；37号顾小满那扇门（框左边靠墙、白天画）装上、能自己关门；方阿婆龛位朝南复建、兄长照片挂旁边。另有三户在核验当天各自收口：6号老头带两只信封来（旧的十一张墙照、回迁以后接着拍，见下条），15号老板娘“锅我带走、人我带回来”兑现、锅搬回店里不摆门口，22号房东与租客在接待桌上把回迁后租期议定并双方签字。
- 6号墙照口径（贯穿至结局）：每周一张、同位同距，脚尖对地上那个胶布十字、手机贴墙上那个粉笔十字、离地一米三，老头自己拍。一月六号头一张，三月十七号第十一张；改造那几个月停过；回迁以后接着拍，墙上那个粉笔十字工人重描过一回、位置没有动。旧墙空响的抹灰铲掉重做，新墙上没有裂，印子追平了。他的口径是“拍到我自己拍不动那天”。写这一户时不得改成十一张以外的数目，也不得写成裂又走了。
- 15号早餐店回迁落点：锅搬回店里、不摆门口（主通道八十八公分摆不下），燃气一户一灶装了表。停业八个月不计租、租期顺延八个月、押金八千延用、头一年四千不涨写下来、后两年按合同谈；经营条件另核，沈姐在跟。老板娘那句“去年我讲，锅我带走，人我带回来——锅带回来了，人我带回来了”是这一户的收口，不得改写成她拿到了补偿款。
- 22号回迁落点：房东与租客在接待桌（桌子搬到一楼）上议回迁后租期，附加条款第六条“回迁后租期另议”底下压着一支笔。房东开四千五、租客出四千二，议定四千三，双方签字。房东这一年没有找租客追过一分钱，孩子没有转学。纸板图六十二个格子里仍有22号——租客那句“我这一户有字”是收口。不得写成房东赶人或租客搬走。
- 新巷陌落成（第072章）：肌理部分保留（梧桐、中段青砖、弄堂口那盏灯换新灯罩旧灯）。主通道最窄八十八公分（其余二十三个钟头口径），早七点到八点不通车，弄堂口外便道十二个集中停车位带充电。新楼两层砖木坡屋面、六十二户独用厨卫、燃气一户一表。便民服务站正式点（工具墙门板重钉、老周头右手能握紧、28号独立钉跟、李甜甜直播照开）。费小军李甜甜聘为服务站协管员（管代收快递、工具借还登记、看车，每月补贴，居委会名义聘），房子对接公租房优先，“从租户变成巷陌的人”。记忆展廊一格一格重新挂，第一格仍是“一九八三 周德顺砌”，两份名单并排，纸板图挂入口、六十二格满。28号自己挂自己那一格（“票我念过了，念过了就挂得住”）；沈姐与林知遥对着七只箱子上的编号逐格核来源。本章结尾意象定为工具墙最外面那一枚空钉子（借出去的工具的位置，明早七点有人来还），不得再与071、075的“5号位置那一间门朝东”收尾重复。
- 样板（第073章）：区里下文，长春里列全市旧住房微更新样本，“探索了不成套旧住房内部改造的资金平衡新口径与社会收益评价方法，可复制可推广”。现场会开在记忆展廊旁，潘副局长三句（程序、成果、钱——换口径平衡了）。程守方带学生来，三条不赞成逐一答了（消防补救到位、密度接受“不解困是另一条路”、资金改名“财政回收”加“社会收益”一行），讲“换口径这件事我想了三十年、长春里是头一个”。孟老师答“那个圈在第一格”。高科长讲三条硬杠全过还没拆平。赵主任讲“我签、我压、我报，如今改成一句：成了”。老周头不参加、坐着修鞋，讲“样板不样板我不懂，鞋修好人回来灯亮日子过下去就是样板”。赵主任年龄口径：叙述里是“今年五十七，再干三年”（二〇二五年十二月起），他在现场会上引用二〇二四年听证会原话时仍说“我今年五十六，我再干四年”——引号内不改，引号外一律用五十七。
- 锥子刻字与去留（第074章）：二〇二六年三月老周头刻“巷陌人家”四个字——旧榆木（拆下来老房梁）、修鞋锥子、左手按稿右手刻、一笔一划刻三天、不让人扶手（28号只按木牌）、没有玻璃（玻璃反光看不清字，同第一格木框）。他讲“巷陌是地方、人家是人，地方和人在一起”“人字一撇一捺互相撑，撑住了就是人家”。木牌一米二乘六十（同工具墙门板尺寸），挂社区活动室墙上。林知遥留任到期，赵主任给两个意思：回滨江（原调令、大项目）或做旧住房微更新指导（把长春里这套——附页、核来源、两本账、从七点四十问起——带到别的弄堂）。老周头把那只铜皮包覆木柄锥子给她，讲“你拿这把锥子去别的弄堂刻别的巷陌人家、每条弄堂都有它自己的四个字、图不是人、线画得再直直不过人走出来的路”。刻字那天李甜甜开着直播，屏幕上有人打“这一笔一划，刻的是四十二年”，老周头当场纠正“四十一年，账是四十一年”——四十一年是修鞋票与挑水账的年数，四十二年是亭子间砌到拆的年数，两个数不得混用。
- 大结局（第075章）：二〇二六年四月社区活动室开放。林知遥接了微更新指导岗、没回滨江，这一个月跑了三个区七条弄堂、穿老周头给的布鞋（左边多钉一枚钉）走弄堂。开放日众人到齐（赵主任再干三年、葛科退休前、潘副局长、程守方带五个学生评“走得最远”、孟老师、各户）。老周头坐亡妻竹凳、摸那四个字“刻得深、摸得出来、人家就记得住”（他是被人推到活动室、从轮椅上挪下来坐到那只竹凳上的，竹凳裂纹上半段填了新蜡）。林知遥穿布鞋从弄堂口走进活动室又走出来，铜钥匙在口袋、锥子在包里，本子写满最后一页（“图不是人，线画得再直，直不过人走出来的路。你先把鞋换了，再进来”），带锥子去第八条弄堂。结尾意象：弄堂口那盏灯、梧桐、服务站木牌亮着；5号位置那一间门朝东开着、老周头坐竹凳正对门看得见弄堂口；活动室白墙上旧榆木木牌“巷陌人家”一笔一划刻得很深。
- 抽户两户落点（第075章补）：5号韩家、33号钱家开放日没有来，人早已搬走，纸板图上那两个格子仍单独标着。林知遥上个月给他们各寄了一张照片，拍的就是那两个格子。韩淑芳回了电话：钱到了，儿子的首付交了，崇明的房子看好了两间。钱卫东没有回话；清明那天他带那双鞋去了墓地，鞋票还在铁皮盒里，盒子上了墙。写这两户时不得写成他们回来参加开放日，也不得写成安置款没有到位。
- 直播场次口径（第064—065章）：头一场七个看客，第二场二十几个，第三场上百；第四场评论区进来一个二〇一九年搬走的人，认得木砧底下抽屉里那第四把铜钥匙（四把钥匙，拴红毛线那把是王阿婆的，最里头一把铜的磨得发亮），屏幕那头只打过来一个字“在”。第四场一百多人，第五场三百，到六月里最多的一场一千二百人在线。李甜甜没有把数字告诉老周头。
- 28号那张五块钱的票：从摊子上放到他自己取回，是六十七天（一月十一号取）。第三卷内随时间推移有“四十五天”“六十天”“六十三天”等中间数，第四卷及以后一律只写六十七天，不得再写成六十天。
- 老周头身体口径（第四卷）：右手随施工期逐月恢复——三月握不紧、五月能握锥子穿线、九月握锤敲钉（慢、外侧多钉两枚）、十二月能握紧、二〇二六年能刻字（慢、费力、刻三天）。不得写成完全康复如初，也不得写成一直不能动手；精细活看恢复、急不来。仍坐轮椅代步（站久了腿麻），未再病倒住院。
- 布鞋与锥子（贯穿道具收束）：林知遥那双老周头给的旧布鞋，后跟磨歪、左边多钉一枚钉（四十一双左边多钉一枚钉的，两双：沈金凤、林知遥），穿到结局未换。老周头那只铜皮包覆木柄锥子，结局交给林知遥，带往别的弄堂。铁皮盒铜钥匙仍在林知遥口袋（盒子上了记忆展廊的墙、钥匙还她一份名分“你是替他讲那四十一年的人”）。
- 新市民落点（副线收束）：费小军、李甜甜（阁楼租户、房东在澳洲、无投票权、回迁分不到房）最终被便民站留下——聘为协管员、公租房优先对接，“房子是房子、地方是地方，出力就是巷陌的人”。李甜甜直播让手艺被看见（最多一场一千二百人在线），“拍从前也拍今天、这就是传承”。28号从九年不出门到学徒、按木牌、名字上名单上墙，“我是这条弄堂的人”。
- 孙姓女人（泵房东边两间）落点：不计入户数，改造期间街道另行安置两处过渡房（附页第十条书面答复、盖章、上墙），台风夜低处进水半尺人转移高处平安；改造后处置写进正文第八条。她讲“我没有户，我有一格”“留档就是以后有人晓得我们住过”。
